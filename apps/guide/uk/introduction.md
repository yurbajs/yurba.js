# Вступ до Yurba.js <Badge type="tip" text="v1.0.0" />

Ласкаво просимо вас ознайомитися з повноцінним посібником по **yurba.js** — потужній та гнучкій бібліотеці для створення ботів, інтеграцій, автоматизації та роботи з [Yurba API](https://docs.yurba.one/overview). Незалежно від того, чи створюєте ви свого першого бота, чи розробляєте складні автоматизовані рішення, цей посібник допоможе вам крок за кроком освоїти все необхідне.


> [!CAUTION] Важливо про ботів 
> Нажаль на цю міть, Yurba.one - не надає можливості у створенні справжніх ботів, через це приходиться використовувати альтернативні шляхи - створюючи аккаунт користувача і використовуючи його

## Швидкий старт

Готові розпочати? Дотримуйтесь цих основних кроків:

1. **[Встановлення](/setup/installation)** - Налаштуйте Node.js та встановіть yurba.js
2. **[Налаштування бот-акаунта](/setup/setting-up-bot-account)** - Створіть та налаштуйте свій бот-акаунт
3. **[Створення проєкту](/development/create-project)** - Ініціалізуйте свій бот-проєкт
4. **[Структура файлів](/development/create-files)** - Створіть основні файли бота
5. **[Організація проєкту](/development/structure)** - Покращте структуру коду

## Передумови

Перед початком переконайтеся, що у вас є:

- **Node.js 20+** - Бібліотека потребує Node.js версії 20 або вище
- **Базові знання JavaScript**
- **Акаунт Yurba.one** - Вам знадобиться акаунт для отримання API токенів

Готові розпочати розробку? Переходьмо до [налаштування середовища розробки](/setup/installation)!
