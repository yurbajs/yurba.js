## Yurba.one: Українська соціальна мережа

**Yurba.one** — це **українська соціальна мережа**, раніше відома під доменами **Yurba.me** та **yurba.ml**, яка позиціонується як сучасна соціальна мережа з сучасним інтерфейсом. Її історія починається задовго до створення власне соцмережі — у 2021 році, коли проєкт розпочинався як **торент-трекер** (спочатку під назвою **TickTracker**), який мав стати альтернативою toloka.to. Наразі Yurba.one перебуває в активній розробці.

## Історія та ключові етапи

Розробка проєкту Yurba почалася у квітні 2021 року. Важливі етапи розвитку включають:

### Початок (2021)

- **Квітень 2021**: Створення Telegram-каналу, анонс українського торент-трекера, а назва змінюється з TickTracker на Yurba.
- **Вересень 2021**: Заснування сервісу **GOLink** (профіль користувача для розміщення посилань), творцем якого був Zeralld (Андрій).
- **Листопад 2021**: Створення музичного сервісу **MuseBase** розробниками **1lya\_sample** (Ілля) та **Zeralld** (Андрій).

### Трансформація (2022–2023)

- **Вересень 2022**: MuseBase входить до проєкту Yurba та анонсується його перетворення на єдину соціальну мережу.
- **Листопад 2022**: **Запуск у відкритому бета-тестуванні** соціальної мережі Yurba на основі MuseBase. Авторизація тоді працювала через зовнішній сервіс **Yurba ID**.
- **Січень 2023**: Припинення роботи Yurba ID та його об'єднання з основною соціальною мережею. Також створено **Yurba Photos** для завантажень зображень.
- **Березень 2023**: Приєднання GOLink до мережі. Back-end мережі було переписано на **Python**, а Front-end використовував простий **HTML у поєднанні з JQuery**.
- **Серпень 2023**: Зміна домену з **yurba.me** на **yurba.one**. Станом на кінець серпня 2023 року мережа вже мала весь базовий функціонал: профілі, систему друзів, сервіс музики та фото, месенджер, а також підтримку української мови.

### Офіційне відкриття та розвиток (2024–2025)

- **Квітень 2024**: Відбувся **офіційний вихід мережі з бета-тестування** (оновлення 2.0.0). Перед цим, у березні 2024 року, **Yurba API було переписано на Go**.
- **Червень 2024**: Вихід у бета-тестування мобільного застосунку **Yurba Mobile 1.0.0 Beta** на Android.
- **Вересень 2024**: Вихід застосунку для Windows, **Yurba Desktop 1.0.1**.
- **Січень 2025**: Вихід застосунку на iOS (**Yurba Mobile 1.0.0**).

## Команда розробників

Соціальна мережа була створена українськими розробниками, серед яких:

- **Ілля Чернов** (відомий за ніками **sample**, **1lya\_sample**)
- **Андрій** (відомий за ніками **jadev**, **Andrew** та раніше **Zeralld**)

## Технологічний стек та інфраструктура

Проєкт використовує власні технологічні рішення:

### Backend
- Перенесений на **Go** (з березня 2024 року)
- Yurba API розташований на окремому піддомені **api.yurba.one**

### Frontend (Власні бібліотеки)
- На початкових етапах використовувався простий HTML у поєднанні з JQuery
- Для роботи з json використовується бібліотека **JSNT (JSoNTools)**, створена ClarityLab
- Розробники також створили **SDP (Styles Design Platform)**, який є функціональним спрощувачем синтаксису CSS

### Додатки
- **Desktop додаток** (Yurba Desktop) написаний на **Electron**
- **Мобільний додаток** (Yurba Mobile) використовує Electron-подібну технологію
