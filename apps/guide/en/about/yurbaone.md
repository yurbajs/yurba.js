**[Yurba.one](https://yurba.one)** is a **Ukrainian social network**, formerly known under the domains **Yurba.me** and **yurba.ml**, which positions itself as a modern social network with a contemporary interface. Its history begins long before the creation of the social network itself — in 2021, when the project started as a **torrent tracker** (initially called **TickTracker**), which was supposed to become an alternative to [toloka.to](https://toloka.to/). Currently, the social network is in active development.

## History and Key Milestones

Development of the Yurba project began in April 2021. Important development stages include:

### Beginning (2021)

- **April 2021**: Creation of Telegram channel, announcement of Ukrainian torrent tracker, and name change from TickTracker to Yurba.
- **September 2021**: Foundation of **GOLink** service (user profile for posting links), created by Zeralld (Andriy).
- **November 2021**: Creation of music service **MuseBase** by developers **1lya\_sample** (Illia) and **Zeralld** (Andriy).

### Transformation (2022–2023)

- **September 2022**: MuseBase joins the Yurba project and its transformation into a single social network is announced.
- **November 2022**: **Launch in open beta testing** of Yurba social network based on MuseBase. Authorization then worked through external service **Yurba ID**.
- **January 2023**: Discontinuation of Yurba ID and its merger with the main social network. Also created **Yurba Photos** for image uploads.
- **March 2023**: GOLink joins the network. The network's back-end was rewritten in **Python**, and the front-end used simple **HTML combined with JQuery**.
- **August 2023**: Domain change from **yurba.me** to **yurba.one**. By the end of August 2023, the network already had all basic functionality: profiles, friend system, music and photo service, messenger, and Ukrainian language support.

### Official Launch and Development (2024–2025)

- **April 2024**: **Official exit from beta testing** (update 2.0.0). Before this, in March 2024, **Yurba API was rewritten in Go**.
- **June 2024**: Beta release of mobile application **Yurba Mobile 1.0.0 Beta** on Android.
- **September 2024**: Release of Windows application, **Yurba Desktop 1.0.1**.
- **January 2025**: Release of iOS application (**Yurba Mobile 1.0.0**).

## Technology Stack and Infrastructure

The project uses its own technological solutions:

### Backend
- Migrated to **Go** (since March 2024)
- Yurba API is located on a separate subdomain **api.yurba.one**

### Frontend (Own Libraries)
- In the initial stages, simple HTML combined with JQuery was used
- For working with json, the **JSNT (JSoNTools)** library is used, created by ClarityLab
- Developers also created **SDP (Styles Design Platform)**, which is a functional CSS syntax simplifier

### Applications
- **Desktop application** (Yurba Desktop) written in **Electron**
- **Mobile application** (Yurba Mobile) uses Electron-like technology

## User Statistics

::: tip Audience Growth
In 2022 ([information from Wikipedia](https://en.wikipedia.org/wiki/List_of_Ukrainian_social_networks)) Yurba had **1.2 thousand registered users**. Currently in 2025 ([from statix](https://me.yubra.one/statix)), **Yurba.one has 1883 registered users, of which 7 are blocked and 52 deleted**.
:::
