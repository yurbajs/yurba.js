# Contributing

## Setup
1. Fork repository
2. Clone: `git clone https://github.com/YOUR_USERNAME/yurba.js.git`
3. Install: `pnpm install`
4. Create branch: `git checkout -b feature/your-feature`
5. Make changes
6. Test: `pnpm run test && pnpm run lint`
7. Commit and push
8. Open pull request

## Development
- Node.js 20+
- Use `pnpm` package manager
- Run `pnpm run build` to build packages
- Run `pnpm guide:dev` for documentation

## Code Style
- Follow existing patterns
- Add tests for new features
- Update documentation if needed
- Pre-commit hooks will format code
